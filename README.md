"The World — 22 Nov 2026" is a single 1024×1024 newspaper front page for Sunday, 22 November 2026. The lead story is COP31 ending without a climate deal in Antalya, Turkey, two days past its deadline after the EU and others rejected a draft text that did not mention fossil fuels. Below it, six panels round out the day: a Russian drone strike on an apartment block in Dymer near Kyiv, a suspected Ukrainian sea drone hitting a Russian warship docked at Benghazi, Iran striking a civilian industrial site in Bahrain, Democrats winning at least 258 US House seats, global stocks falling as the AI sell-off deepens, and a candy factory fire in Indonesia with 34 workers missing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` into the output directory. It needs no network access and writes the same bytes on every run.
